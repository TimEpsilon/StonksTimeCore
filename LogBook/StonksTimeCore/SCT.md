
# Stonks Currency Translator
Maps an item to a value, representing the amount of money one can get out of a single item. This can then be exchanged in time.

# Currencies
## Summary

	> 1 -> M-Cent
	> 8 -> M-Dime
	> 16 -> M-Drachm
	> 64 -> M-Doubloon 
	> 512 -> M-Crown
	> 4096 -> M-Coin
	
## M-Cent
Inspired by current day cents.

A cent, copper colored (see Spur palette, but a bit more weathered like the copper block), maybe a 1 in the center, no face.
